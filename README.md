# 티티왁싱 정적 사이트

Cloudflare Pages에서 빌드 명령 없이 배포하는 순수 HTML/CSS/JS 사이트입니다.

## 배포
- Framework preset: None
- Build command: 비워두기
- Build output directory: `/` (저장소 루트에 이 폴더 내용을 올린 경우)

- brazilian-waxing.html

## 실제 도메인 연결 후
`https://ttwaxing.pages.dev` 문자열을 실제 도메인으로 일괄 변경하세요. 대상: HTML canonical/OG/구조화데이터, sitemap.xml, rss.xml, robots.txt.

## 운영 정보
실제 네이버 예약, 카카오톡, 전화번호, 주소, 영업시간을 제공받으면 CONTACT 페이지와 구조화데이터에 추가하는 것을 권장합니다. 현재 고객 화면에는 제작자용 안내 문구나 가짜 연락처를 노출하지 않습니다.

## 코드 편집
HTML 파일은 GitHub 웹 편집기에서 바로 수정하기 쉽도록 태그별 줄바꿈과 들여쓰기를 적용했습니다. JSON-LD와 XML도 읽기 쉽게 정리되어 있습니다. 빌드 과정은 필요하지 않습니다.
